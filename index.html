0先搞懂：你在干什么

别一上来就背「9610/9810」或「一般纳税人」。先用大白话看清整件事。

一句话：湖北随州备货 → 货运到海外仓/平台仓 → 在 TikTok Shop / Shopee / Lazada 卖东南亚（汽车应急、五金工具、一次性纸碗）→ 由仓履约发货；平台把货款结算给你。中国侧管「出关 + 可能退税」，国外管「销售税/增值税或平台代扣」。默认不是每单小包直邮。

跨境电商卖货 = 三件事叠在一起

  1. 卖：在平台上架、接单（经营动作）
  2. 出：货物离开中国（海关报关 / 清单）
  3. 账：钱怎么进公司账户、税怎么算、票怎么留（财务动作）

这本手册主要教第 3 件，但第 2 件不过关，账也做不下去——所以前面会有「能不能出口」。

你现在要记住的唯一目标

学会问自己：这单货用什么方式出的中国（海外仓备货常见 9810 或一般贸易 0110）？有没有增值税专用发票？平台结算单上的扣税是不是另一回事？能分清这三问，后面章节才不晕。

1钱怎么走、税大概指什么

财务入门：先分清「货款」和「税」不是一回事；中国税和国外税也不是一回事。

钱大概怎么走（简化）

  1. 买家在平台付款 → 钱先在平台/支付通道里
  2. 平台扣佣金、可能代扣当地税 → 剩余结算到你的收款账户
  3. 你在中国侧还有采购付款、运费、报关费等成本和进项票

「税」在这本手册里常见有三种（别混）

  1. 出口退税：中国把你国内已交的一部分增值税退回来（有条件）。影响现金流。
  2. 境外销售税 / VAT（增值税）：卖到国外时，销售国可能要税；有的由平台从货款里代扣。
  3. 企业所得税等：公司赚了利润后在中国要交的税（本手册不展开细节，但无票免税时可能有核定征收等规则）。
例子：纸碗卖到越南。平台可能代扣越南税（你账户少一截）；同时这批货若在中国合法出口且有专票，你还可能另办中国出口退税。两边分开算。

这一步你做什么

结算单上常有：销售额、佣金、代扣税、实际到账——先会圈这四项。

你做什么打开最近一笔平台结算单，圈出：销售额、佣金、代扣税、实际到账
找谁平台卖家中心「财务/结算」；不懂就问会计或代理
准备什么一张结算截图 + 对应订单号，后面学对账要用

2能不能卖 / 能不能出口

财务开干前的关：货不合法，退税申报和平台收款都可能出问题。

怎么判断（大白话）

  1. 是不是国家禁止出口的东西（濒危、特定化学品等）→ 直接不能做
  2. 要不要出口许可证 / 两用物项许可 → 没证不能出
  3. 是不是危险运输货（锂电池、气雾罐、灭火器）→ 能卖也要按危运规则，成本更高
  4. 有没有商标侵权 → 平台封店 + 海关风险

你们三类货：普通工具 / 无电应急配件 / 纸碗 —— 多数不是整类禁止；重点盯锂电应急电源、气雾灭火器、开刃刀具、假品牌、纸碗食品接触质量。

不要死记目录，用工具查： 打开禁限可查清单 搜「锂电」「纸碗」「刀具」
你做什么把在售 SKU 列成表：品名、是否含电池/气雾/刀具、品牌是否自有
找谁货代（运输限制）、属地海关（归类疑问）、平台违禁品页
准备什么产品说明书/照片、成分或电池参数、商标授权书（如有）

3选出口模式（决定你后面怎么退税）

本手册默认场景是「货运到海外仓/平台仓再销售」。海关用几个数字代码区分出货方式；选错了，财务对账和退税路径会对不上。

四种常见说法（先记场景，再记数字）

  1. 先堆海外仓再卖 → 常碰 9810　你们最常见
  2. 传统一般贸易备货仓出货 → 常碰 0110（海外仓场景也很常见，货代说法不一）
  3. 卖给境外公司 → 常碰 9710
  4. 对照：小包直邮给个人买家 → 才常碰 9610（非本手册主线）
你们走海外仓时的财务主路径：有专票 + 报关离境 + 收汇 + 退税。务必书面确认本票监管方式是 9810 还是 0110（货代说法不一，不要猜）。 9610「无票免税」是综试区零售直邮路径，海外仓一般套不上。
对照说明：9610 在综试区符合条件可能「无票免税」（不退税，只是出口环节免增值税）；9710/9810/0110 更常走「有票退税」。无票免税扩不到 9710/9810——这是税务机关公开答复口径。

货代手里通常能看到监管方式代码；也可以看 报关单 或跨境电商申报清单。

你做什么问清货代/报关行：本票是 9810 还是 0110？（偶有直邮小包再问是否 9610）
找谁货代、报关行；综试区政策见 3b 随州核查（用来排除无票免税幻想）
准备什么最近一份报关单或入仓证明复印件/截图

3b随州是不是综试区？（决定你能不能「无票免税」）

若你主做海外仓，本章主要用来排除「无票免税幻想」。「无票免税」主要给综试区里的跨境电商零售出口（常见 9610）。公司在随州，先查清自己算不算。

结论（检索日 2026-10-27）： 随州不是综试区。 ① 已公开的国务院批复名单中未见「随州市」；湖北已见批复的综试区城市包括： 武汉（2018）、黄石（2019）、襄阳（2022）、鄂州（2025）等。 ② 随州市商务局2025-11-21 公开答复写明： 「随州尚未获批跨境电商综试区……导致跨境电商企业无法享受无票免税和所得税核定征收等税收优惠政策。」（证据 A） ③ 本地有「跨境电商产业园」（如曾都区）≠ 国务院批复的综试区——入园不能自动兑现无票免税。

4票证与备案（财务真正开工）

想退税，先把「公司身份」和「进项票」准备好。这章是做账基础。

你至少要弄清这几张「身份证」

  1. 营业执照公司（个体户也能做部分业务，但退税实务里公司更常见）
  2. 海关备案（自己名义报关需要）
  3. 一般纳税人（对比： 小规模纳税人往往更难走有票退税）
  4. 出口退（免）税备案（第一次申报退税前向税务办理）
  5. 增值税专用发票（专票）：向工厂/供应商要
  6. 单一窗口账号（报关/退税常用入口之一）

4a采购 → 货代 → 入海外仓（实操主线）

默认场景：国内备货，货运到海外仓/平台仓再销售。本章把「买货到货进仓」拆成能照着做的步骤。监管方式常见问清是 9810 还是 0110；小包直邮 9610 仅作对照。

一句话流程：找供应商拿专票 → 货代订舱报关 → 货物离境并入海外仓 → 公司留齐合同/专票/报关单/运单/入库证明 → 后面才能安心冲退税。

① 找供应商：票、品名、合同怎么对齐

  1. 要增值税专用发票（专票）：抬头是你公司全称；税率与品名如实；能退税的前提常是「有专票」。
  2. 品名规格对齐：发票品名、合同品名、箱单、报关品名尽量一致（材质、型号、单位别各写各的）。对不齐时，事后退税容易被卡住。
  3. 合同与付款留痕：采购合同/订单、付款回单、送货单都留档；现金无痕最难自证。
  4. 含锂电/气雾等：提前问工厂要说明书、UN38.3 或检测资料，后面货代要用。
你做什么下单前跟供应商说清：要专票、品名怎么写、交期与送货地址（工厂→货代仓/装柜点）
找谁供应商财务（开票）、你司采购/会计（对票）、报关行（预归类税号建议）
准备什么营业执照信息、开票资料、SKU 规格表、采购合同模板

② 找货代：订舱、报关、入仓预约

  1. 订舱 / 排期：告诉货代目的仓（国家、仓码）、体积重量、是否含电/危品。
  2. 书面确认监管方式：本票是 9810 还是 0110？不要口头含糊；截图或邮件留存。（偶有直邮小包才再问是否 9610——对照，非主线。）
  3. 提供单证：商业发票、装箱单（箱单）、合同；货代据此报关。
  4. 危品/锂电额外材料：UN38.3、危包证、MSDS 等按货代清单补齐。
  5. 入仓预约与仓单：货到海外仓前预约；入仓后拿 入库证明 / 仓单（9810 退税常要这类证明）。
  6. 费用清单：运费、报关费、仓租、操作费分别要发票/账单，方便入账。
你做什么把本票「监管方式代码」写进邮件让货代确认；核对报关草单品名数量金额
找谁货代操作、报关行、海外仓/平台仓客服（预约入库）
准备什么发票箱单合同、产品说明书/危品资料、收件仓地址与仓码

  1. 采购合同 / 订单 + 付款回单
  2. 增值税专用发票（PDF + 勾选认证截图更好）
  3. 报关单（或申报信息）——看清监管方式代码
  4. 运单 / 提单（海运提单、空运运单等）
  5. 海外仓入库单 / 入仓证明 / 库存截图
  6. 平台仓租、货代运费/报关费发票或账单
对照提醒：若偶发国内小包直邮碰 9610，单证逻辑不同（更偏清单核放、交易物流收款数据）；海外仓主线仍按上面「专票 + 报关离境 + 入仓证明」准备。随州非综试区，一般别指望 9610 无票免税。

5出口退税怎么做（按顺序执行）

核心财务章。先满足条件，再按步骤申报。数字税率请自己用官方查询，手册不编造。

能不能退：四个基本条件（货物）

  1. 卖给境外单位或个人
  2. 向海关报关并实际离境
  3. 会计上做销售
  4. 按规定收汇（外汇收到合规）

另外：外贸企业通常要有匹配的专票等 进项税额凭证； 生产企业常用「免抵退」； 外贸企业常用「免退税」——细节问会计，先抓住「有票 + 报关 + 收汇」。

完整步骤（照着做）

  1. 备案 — 找主管税务机关 / 电子税务局；准备备案表
  2. 拿专票 — 找供应商；核对品名数量尽量与报关一致
  3. 报关离境 — 找货代报关行；拿到报关信息
  4. 收汇 — 找银行；原则上报关出口次年 4 月 30 日前（有例外规则）
  5. 网上申报退税 — 电子税务局或单一窗口
  6. 留存单证 — 合同、运单、委托报关等备查

模式差异（财务决策）

· 9810 海外仓（主线）：有专票可退税；可了解「离境预退、销售再核算」；备海外仓入仓证明等。
· 0110 一般贸易备货仓（并列常见）：经典有票退税路径；海外仓出货时货代也可能报 0110——务必书面确认。
· 有专票：优先冲退税（9810/0110/9710，以及偶发 9610 直邮，都可能，看是否符合条件）。
· 对照：没专票 + 在综试区 + 9610：研究「无票免税」（免的是出口环节增值税，不是退一笔钱到账）。小包直邮且综试区才可能；海外仓主线通常不看这条。

6东南亚报税与对账（越南代扣拆开讲）

中国出口退税和平台代扣是两本账。越南政策要分清：你是「个体/家庭卖家」还是「公司卖家」。

先建立记账习惯（三国通用）

  1. 平台结算单分栏：销售额、佣金、运费相关、广告/仓租、代扣税、实际到账
  2. 中国出口退税/免税另科目，不要和代扣税对冲混记
  3. 每月导出 CSV，和订单、退货单三方勾稽

越南：个体/家庭 vs 公司（务必拆开）

① 个体 / 家庭卖家（hộ, cá nhân）
议定 117/2025/NĐ-CP 管的就是这类主体：自 2025-07-01 起，有支付功能的电商平台须代扣 VAT + 个人所得税。
商品类常见代扣比例（居民个人，法令口径）：VAT 1% + PIT 0.5%（合计约 1.5% 从应税收入扣）；服务类更高（VAT 5% + PIT 2%）。以平台结算明细为准。

② 公司卖家（Công ty 等组织）

7三类品财务注意（加厚：票证 · 运费危运 · 平台扣费）

合规成本会进费用；票证不齐会卡退税；平台扣费要和结算单对上。下面按品类拆开写。

A. 汽车应急类（尤其含锂电池 / 气雾 / 灭火器）

  1. SKU 分账：无电配件（三角牌、拖车绳等）与含锂电应急电源、气雾补胎液、灭火器分开建存货与成本科目，别混在一个「应急包」成本里。
  2. 票证：采购专票品名写清「启动电源/锂电池」等；留存 UN38.3 测试报告、危包性能/使用鉴定（如需）扫描件，和报关资料一归档。
  3. 运费 / 危运成本：锂电常按第 9 类危险货物运输，空运更严、海运要包装与标记——运费、鉴定费、检测费全部进成本或「合规费用」，报价时预留毛利。
  4. 平台扣费对账：结算单里佣金、运费险、仓租、广告费与「危运加收」分开列；退货导致的扣款单独一栏，方便月末核对。
  5. 官方：锂电池出口包装要求 · 报检规定（出境危险货物包装鉴定）

B. 工具类

  1. 票证：专票品名与报关一致（扳手、千斤顶等）；品牌授权书与采购合同一起留存，避免侵权纠纷坏账。
  2. 运费：重货运费占比高，按 SKU 分摊运费到单位成本，否则毛利失真。
  3. 开刃刀具：宁可不做；一旦平台下架/海关扣货，损失走「资产减值/营业外」前先问会计口径。
  4. 平台扣费：大件可能有偏远地区运费补差，结算导出后与订单重量核对。
  5. 官方：两用物项出口管制清单（高精度设备才紧张）· 2026 出口许可证目录

C. 一次性纸碗 / 食品接触材料（出口常见要求）

  1. 先分清：纸碗是「接触食品的容器」，一般不是「食品本身」。出口食品生产企业备案那套（海关总署令第 249 号）主要管食品；纸碗更常落在商品检验 / 食品接触质量 + 目的国要求。
  2. 质量与标签（财务要留的文件）：向工厂要检测报告/合格证明；包装建议有「食品接触用」等用途说明、材质、生产商信息（国内进口侧答疑常用 GB 4806.1 / GB 4806.8 作质量对标——出口以目的国或合同为准）。
  3. 报检：若该税号列入必须实施检验的进出口商品目录（法检），出境须按规定报检，未经检验或不合格不得出口（《商检法实施条例》）。出境报检一般要合同、发票、装箱单，并附检验合格证或检测报告（见报检规定）。
  4. 税号举例（归类需海关确认，勿直接照抄报关）：海关答疑称纸质餐具常归入 4823 项下；实务中纸杯等曾见编码如 48236900xx，且历史上可能带法检监管条件——以你合同当年《法检目录》+ 属地海关归类为准。
  5. 成本：检测费、报检费、轻泡货运费（体积重）全部进成本；平台包装破损赔付单独登记。
  6. 官方： 出入境检验检疫报检规定 · 进出口商品检验法实施条例（法检不准出口等） · 海关答疑：纸质餐具与 4823 / GB4806（偏进口口径，出口作质量参考） · 海关总署令第 249 号（出口食品，搭售调料时再看）

名词小词典（看不懂点开）

正文里悬停彩色词也能看解释。这里集中复习。

出口退税

货物合法出口后，国家把你在国内环节已交的增值税（有时消费税）按规定退还或免征出口环节税。不是国外平台给你退钱。

增值税专用发票（专票）

能单独体现税额的发票。外贸出口退税常靠它证明进项税。

一般纳税人

增值税纳税人的一类。通常可领用专票，也是很多出口退税情形的前提。

9810 / 0110 / 9710 / 9610

海关监管方式代码。本手册默认海外仓：9810=出口到海外仓备货再销售；0110=一般贸易（备货仓也很常见）；9710=跨境电商 B2B 直邮；9610=零售直邮（对照，非默认）。决定申报与退税路径。

综试区 · 无票免税

跨境电商综合试验区里，9610 零售出口若拿不到有效进货凭证，符合条件可免增值税/消费税（不是退税到账）。须国务院批复设立的城市才算综试区。

跨境电商产业园 ≠ 综试区

地方建的产业园/孵化园可提供仓储物流培训，但没有国务院综试区批复就不能自动享受无票免税等综试区税收政策。随州本地产业园与「尚未获批综试区」可同时成立。

VAT / GST

国外常见的增值税/商品服务税。可能由卖家缴纳或平台代扣。

收汇

出口货款从境外收到境内合规账户。退税通常有时限要求。

UN38.3

锂电池航空/海运常见的安全测试要求。应急启动电源常会遇到。

结算单 / 佣金

结算单=平台打款明细；佣金=平台抽成。财务对账从这两项开始。

货代 / 报关单

货代帮你出货清关；报关单是海关申报记录，退税常要和专票核对。

进项税额

买货时发票上的税额。出口退税退的往往就是符合条件的进项税额。

免抵退 / 免退税

两种退税计算方法：生产企业常用免抵退；外贸买货出口常用免退税。

小规模纳税人

相对一般纳税人的类型，通常更难走「有票退税」，很多团队会先升级一般纳税人。

单一窗口

国际贸易单一窗口网站/系统，报关、跨境清单、部分退税申报常在这里办。

SKU

Stock Keeping Unit，单个商品型号/库存单位。财务和合规都要按 SKU 分清楚。

食品接触材料

会碰到食物的碗、杯、餐盒等。质量不合格可能影响出口与平台上架，检测费要进成本。

危险货物（危运）

运输时有燃爆等风险的货（如许多锂电池）。不是「禁止出口」，但包装、申报、运费更严。
